# Drae 宠物乐园 2.3.0

发布日期：2026-11-05 · 升级范围：2.2.1 → 2.3.0

## 登录与注册

- 登录和注册增加六位数字与字母验证码，验证码可点击刷新。
- 验证码设置有效期，使用后失效，提升账号安全性。

## 宠物照料与活动

- 修复首次初始化后钱包未及时创建的问题。
- 优化被雇佣打工时的自动召回，改善召回成功后的状态提示。
- 完善好友互动、自动照料及活动执行过程中的状态处理。

## QQ 官方机器人

- 管理端支持配置、连接和断开官方 QQ 机器人；连接意外中断后自动重连。
- 支持使用绑定码关联售后群及用户的乐园账号。
- 已绑定群可使用签到和“我的金币”指令，签到奖励范围可在后台设置，并可查看签到记录。
## 安装包

- 新增 Windows ARM64 和 Linux ARM64 安装包，同时保留 x64 版本。

## 升级方式

停止旧版前后端，备份原有 `data` 目录，再将其复制到 2.3.0 的独立解压目录并启动。原有账号和配置会继续使用。

由于二开版本过多，所以采用闭源方式发布，但是允许运营。
