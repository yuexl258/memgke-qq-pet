# Drae 宠物乐园 2.5.1

更新日期：2026-11-08 · 升级范围：2.5.0 → 2.5.1

## 页面加载修复

- 修复打包时遗漏下划线开头公共脚本的问题，解决登录页空白、宠物小屋、自动照料、QQ 账号、用户端外观、系统更新等页面加载失败。
- 缺失的脚本、样式和图片返回明确的 404，避免将首页 HTML 当作脚本执行。
- 首页禁止缓存，降低升级后继续引用旧资源的概率；页面加载失败时显示刷新提示。

## Linux 更新修复

- 更新前检查进程身份并准备好新程序和旧版备份，主动停止前后端，避免无限等待后端退出。
- 退出等待设为 30 秒，识别已退出的僵尸进程，超时取消安装；更新助手独立运行并记录日志。
- 保留前端的后端地址、监听地址和端口等配置，以及后端原工作目录，避免重启后访问错误的相对数据库路径。
- 新程序启动后立即退出时回退旧程序，保留失败暂存目录及恢复备份。
- 更新请求和助手使用独立锁；重试使用新的安装暂存目录，避免旧文件阻止解压或被误删。
- 更新提交后等待目标版本恢复再刷新页面；等待超时给出日志检查提示，离开页面停止轮询。
- 安装或下载期间禁止重复操作和修改下载源，切换下载源后清除旧检查结果。
- systemd 托管和容器主进程继续采用手动更新。

## 用户端外观与备案

- 经典乐园支持后台配置主题色、侧栏、间距、圆角、字号、内容宽度和欢迎语，并提供预览。
- 登录页、手机导航、弹窗和好友选择器跟随用户端主题；切换到管理后台时恢复管理端样式。
- 修复手机弹窗、长文本和表单控件显示，保留 Drae 名称与标志。
- 管理端新增备案号设置；未填写时隐藏，填写后点击跳转至工信部备案查询页。
- 外观和备案配置均由管理员修改，普通用户不可更改。

## 安装包与升级

- 提供 Windows x64、Linux x64、Linux ARM64 完整安装包，本版不编译 Windows ARM64。
- 前后端版本统一为 2.5.1，安装包附启动脚本、说明和 SHA-256 校验清单。
- 从 2.5.0 或更早版本升级时，建议手动停止旧前后端，备份数据，再替换本版配套程序。旧更新助手不包含本次修复，首次升级不应依赖旧助手完成。
- 保留实际使用的数据库、工作目录和启动环境；不会替换账号、好友或任务配置。
- 本版延续 2.5.0 的每日任务、指令调度、福袋分批领取和当日日志保留规则。

由于二开版本过多，所以采用闭源方式发布，但是允许运营。
