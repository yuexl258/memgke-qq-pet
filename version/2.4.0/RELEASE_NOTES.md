# Drae 宠物乐园 2.4.0

发布日期：2026-11-06 · 升级范围：2.3.1 → 2.4.0

## 自动更新

- 管理端新增更新页面，可检查 GitHub 最新发行版本并查看 Markdown 格式更新日志。
- 管理端访问时会在后台检查更新；发现新版本时提示管理员前往更新页面。
- 支持手动检查、选择国内镜像节点或直连，并支持自定义下载节点。
- 自动更新会根据运行平台和 CPU 架构选择对应发行包，下载支持断点续传。
- 当前环境不支持自动替换时，可将匹配的发行包下载到运行目录，并按页面提示完成更新。

## 发行包

- 提供 Windows x64、Windows ARM64、Linux x64、Linux ARM64 四种发行包。
- 每个发行包包含前端、后端、启动脚本、使用说明、图标和 SHA-256 校验文件。

## 升级方式

停止旧版前后端，备份原有 `data` 目录，再将新版本解压到独立目录并复制数据目录后启动。

由于二开版本过多，所以采用闭源方式发布，但是允许运营。
